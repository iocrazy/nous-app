# Smart Organization System - PRD

> **Version**: 1.0
> **Date**: 2026-01-19
> **Status**: Approved for Implementation

## 1. Overview

### 1.1 Background

MediaHub 用户积累了大量下载内容（1000+），面临以下痛点：
- **找不到东西** - 内容太多，搜索效率低
- **分类混乱** - 缺乏有效的组织方式
- **存储压力** - 不知道哪些内容可以清理

### 1.2 Goals

构建一套 **全自动智能整理系统**，实现：
1. 自动内容分类和标签生成
2. 自然语言语义搜索
3. 智能收藏夹动态管理
4. 基于行为的清理建议

### 1.3 Non-Goals

- 不改变现有的物理存储结构（已按年月归档）
- 不涉及多平台扩展（仅抖音）
- 不涉及移动端/PWA（后续迭代）

### 2.2 Core Principles

- **Virtual Organization**: 标签和收藏夹是数据库记录，不移动物理文件
- **Hybrid Analysis**: 元数据粗分类 + AI 精分类，平衡成本和效果
- **Tiered Processing**: 视觉分析分级执行，控制 API 成本
- **User Confirmation**: 去重和清理需用户确认，避免误删

## 3. Feature Specifications

### 3.1 Tag System

#### 3.1.1 Tag Types

| Type | Description | Example | Editable |
|------|-------------|---------|----------|
| **System Tag** | Auto-generated by AI | `Food`, `Tutorial`, `Dance` | No |
| **User Tag** | Created by user | `To Edit`, `Client A`, `Inspiration` | Yes |
| **Time Tag** | Auto-generated by date | `2026-01`, `2026-Q1` | No |

```
       │
       ├── High confidence ──▶ Assign tag directly

       └── Low confidence ───▶ Call AI for classification

                                      ▼

                              │ 3. AI Analysis  │
                              │    (GPT/Claude) │
                              └─────────────────┘
                                      │
```

### 3.2 Visual Content Analysis

#### 3.2.1 Three-Tier Analysis Strategy

| Level | Trigger | Content | Cost |
|-------|---------|---------|------|
| **L1 Basic** | Auto on download | Cover image only | ~$0.001 |
| **L2 Standard** | User request / Batch job | Cover + 3 keyframes | ~$0.005 |
| **L3 Deep** | Manual trigger | Full video analysis | ~$0.05 |

#### 3.2.2 L1 Analysis (Auto)

```
Cover Image
     │
     ▼
┌─────────────────────────────────────┐
│ Multimodal AI (GPT-4o / Claude)     │
│                                     │
│ Prompt:                             │
│ "Analyze this video cover:          │
│  1. Main content category           │
│  2. Scene description (indoor/      │
│     outdoor/location)               │
│  3. People description (if any)     │
│  4. Key objects                     │
│  5. Overall mood/style"             │
└─────────────────────────────────────┘
     │
     ▼
Store: visual_description, detected_objects, detected_scenes
```

#### 3.2.3 L2 Analysis (On-demand)

```
Video File
     │
     ▼
┌─────────────────────────────────────┐
│ FFmpeg: Extract keyframes           │
│ - Cover image                       │
│ - Frame at 25% duration             │
│ - Frame at 50% duration             │
│ - Frame at 75% duration             │
└─────────────────────────────────────┘
     │
     ▼
┌─────────────────────────────────────┐
│ Multimodal AI: Analyze all frames   │
│                                     │
│ Additional extraction:              │
│ - People actions                    │
│ - Scene transitions                 │
│ - Text/subtitles (OCR)              │
│ - Products/brands                   │
└─────────────────────────────────────┘
     │
     ▼
Update: full analysis + regenerate embedding
```

#### 3.2.4 L3 Analysis (Manual)

- Upload full video to multimodal AI
- Extract: plot summary, action sequences, audio transcript
- Highest accuracy, highest cost
- Recommended for important/frequently-used content

#### 3.3.2 Embedding Generation

**Content sources for embedding:**
1. Title
2. Description
3. Author name
4. System tags
5. User tags
6. Visual description (from AI analysis)
7. Detected objects/scenes/people
8. OCR text content

**Embedding model:** OpenAI text-embedding-3-small (1536 dimensions)

#### 3.3.3 Search Examples

| Query | Interpretation |
|-------|----------------|
| "上个月的美食视频" | Time filter + tag filter |
| "穿白裙子跳舞的" | Vector search on visual_description |
| "点赞超过10万的教程" | SQL: digg_count > 100000 AND tag = 'Tutorial' |
| "有猫的视频" | Vector search: detected_objects contains 'cat' |

### 3.4 Smart Collections

#### 3.4.1 Collection Types

| Type | Description | Update |
|------|-------------|--------|
| **Static** | Manual add/remove | User action |
| **Smart** | Rule-based, auto-matching | Real-time / Scheduled |

#### 3.4.2 Rule Definition

```json
{
  "match": "all",
  "conditions": [
    {
      "field": "tags",
      "operator": "contains",
      "value": "Food"
    },
    {
      "field": "created_at",
      "operator": "within",
      "value": "30d"
    },
    {
      "field": "digg_count",
      "operator": ">=",
      "value": 10000
    }
  ]
}
```

#### 3.4.3 Supported Operators

| Field | Operators | Example |
|-------|-----------|---------|
| `tags` | contains, not_contains | Has "Food" tag |
| `author` | equals, contains | Author name contains "Chef" |
| `created_at` | within, before, after | Within last 30 days |
| `digg_count` | >=, <=, between | Likes >= 10000 |
| `duration` | >=, <=, between | Duration > 60s |
| `aweme_type` | equals, in | Only videos / Only carousels |
| `visual_description` | contains | Description contains "beach" |
| `analysis_level` | >=, equals | Has L2+ analysis |
| `view_count` | >=, <=, equals | Viewed >= 5 times |

#### 3.4.4 Preset Smart Collections

| Name | Rule |
|------|------|
| 📁 This Week | created_at within 7d |
| 📁 High Engagement | digg_count >= 100000 |
| 📁 Long Videos | duration >= 180s |
| 📁 Image Carousels | aweme_type = 2 |
| 📁 Untagged | user tags is empty |
| 📁 Not Analyzed | analysis_level = 'none' |
| 📁 Never Viewed | view_count = 0 AND created_at before 7d |

### 3.5 Cleanup Suggestions

#### 3.5.1 Behavior Tracking

Track user interactions:
- `view`: User opened detail view
- `play`: User played video
- `share`: User shared/exported
- `download_again`: User re-downloaded file

#### 3.5.2 Cleanup Rules

| Suggestion | Rule | Priority |
|------------|------|----------|
| **Never Viewed** | view_count = 0 AND age > 30 days | High |
| **Long Inactive** | last_viewed_at > 90 days ago | Medium |
| **Large Low-Use** | storage_size > 100MB AND view_count < 3 | Medium |
| **Author Overflow** | Same author > 20 videos, suggest by engagement | Low |
| **Low Quality** | digg_count < 1000 AND never viewed | Low |

#### 3.5.3 Cleanup Actions

| Action | Description |
|--------|-------------|
| **Delete File Only** | Remove local file, keep metadata (can re-download) |
| **Delete Completely** | Remove file + database record |
| **Move to Trash** | Move to trash folder, auto-delete after 30 days |
| **Mark as Keep** | Flag as "never suggest cleanup" |

## 4. Database Schema

### 4.1 New Tables

#### tags
```sql
CREATE TABLE tags (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(50) NOT NULL,
    type VARCHAR(20) NOT NULL CHECK (type IN ('system', 'user', 'time')),
    color VARCHAR(20),
    icon VARCHAR(50),
    user_id UUID REFERENCES auth.users(id),  -- NULL for system tags
    created_at TIMESTAMP WITH TIME ZONE DEFAULT now(),

    UNIQUE(name, type, user_id)
);

CREATE INDEX idx_tags_type ON tags(type);
CREATE INDEX idx_tags_user ON tags(user_id);
```

#### video_tags
```sql
CREATE TABLE video_tags (
    video_id UUID REFERENCES douyin_videos(id) ON DELETE CASCADE,
    tag_id UUID REFERENCES tags(id) ON DELETE CASCADE,
    confidence FLOAT,  -- For system tags, 0-1
    source VARCHAR(20) CHECK (source IN ('auto', 'manual', 'ai')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT now(),

    PRIMARY KEY (video_id, tag_id)
);

CREATE INDEX idx_video_tags_video ON video_tags(video_id);
CREATE INDEX idx_video_tags_tag ON video_tags(tag_id);
```

#### video_analysis
```sql
CREATE TABLE video_analysis (
    video_id UUID PRIMARY KEY REFERENCES douyin_videos(id) ON DELETE CASCADE,

    -- Analysis level
    analysis_level VARCHAR(10) DEFAULT 'none'
        CHECK (analysis_level IN ('none', 'L1', 'L2', 'L3')),

    -- Visual analysis results
    visual_description TEXT,
    detected_objects JSONB DEFAULT '[]',
    detected_scenes JSONB DEFAULT '[]',
    detected_people JSONB DEFAULT '[]',
    detected_text TEXT,  -- OCR results

    -- Embedding for semantic search
    full_text_for_embedding TEXT,
    content_embedding vector(1536),

    -- Metadata
    analysis_model VARCHAR(50),
    analysis_cost DECIMAL(10, 6),
    analyzed_at TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT now(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT now()
);

-- Vector similarity search index
CREATE INDEX idx_video_analysis_embedding
    ON video_analysis USING ivfflat (content_embedding vector_cosine_ops)
    WITH (lists = 100);
```

#### smart_collections
```sql
CREATE TABLE smart_collections (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    icon VARCHAR(50),
    description TEXT,

    -- Rule definition
    rules JSONB NOT NULL,

    -- Cache
    cached_video_ids UUID[],
    cached_count INT DEFAULT 0,
    cached_at TIMESTAMP WITH TIME ZONE,

    -- Settings
    is_preset BOOLEAN DEFAULT false,
    sort_by VARCHAR(50) DEFAULT 'created_at',
    sort_order VARCHAR(10) DEFAULT 'desc',

    created_at TIMESTAMP WITH TIME ZONE DEFAULT now(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT now()
);

CREATE INDEX idx_smart_collections_user ON smart_collections(user_id);
```

#### video_access_logs
```sql
CREATE TABLE video_access_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    video_id UUID NOT NULL REFERENCES douyin_videos(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    action VARCHAR(20) NOT NULL
        CHECK (action IN ('view', 'play', 'share', 'download_again', 'export')),
    metadata JSONB,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT now()
);

CREATE INDEX idx_access_logs_video ON video_access_logs(video_id);
CREATE INDEX idx_access_logs_user ON video_access_logs(user_id);
CREATE INDEX idx_access_logs_created ON video_access_logs(created_at);
```

## Appendix B: AI Prompts

### Content Classification Prompt

```
Analyze this Douyin video metadata and classify it:

Title: {title}
Description: {description}
Author: {author}
Original Tags: {original_tags}

Classify into ONE primary category:
- Food, Tutorial, Comedy, Dance, Music, Beauty, Fashion, Gaming, Pets, Travel, Tech, Sports, Vlog, Other

Also provide:
1. Confidence score (0-1)
2. Secondary category (if applicable)
3. Key themes (up to 3)

Respond in JSON format:
{
  "primary_category": "",
  "confidence": 0.0,
  "secondary_category": "",
  "themes": []
}
```

### Visual Analysis Prompt (L1)

```
Analyze this video cover image and describe:

1. Main content category (Food/Tutorial/Comedy/Dance/Music/Beauty/Fashion/Gaming/Pets/Travel/Tech/Sports/Vlog/Other)
2. Scene description (indoor/outdoor, specific location if identifiable)
3. People description (gender, estimated age, clothing, action)
4. Key objects visible
5. Text visible in image (if any)
6. Overall mood/style

Respond in JSON format:
{
  "category": "",
  "scene": {"type": "", "location": ""},
  "people": [{"gender": "", "age_range": "", "clothing": "", "action": ""}],
  "objects": [],
  "text": "",
  "mood": ""
}
```

### Text2SQL Prompt

```
Convert this natural language query to a SQL WHERE clause for searching videos.

Available columns:
- title (TEXT): Video title
- description (TEXT): Video description
- author_nickname (TEXT): Author name
- digg_count (INT): Like count
- comment_count (INT): Comment count
- share_count (INT): Share count
- duration (INT): Duration in seconds
- created_at (TIMESTAMP): Download date
```
