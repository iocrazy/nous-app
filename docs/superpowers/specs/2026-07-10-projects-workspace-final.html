项目即工作区 — 模块并列,零跳转FINAL

不再有 "Studio" 入口:打开项目 = 直接身处创作环境。编辑器的模块栏升为项目侧栏——剧集、脚本、分镜、人物、场景、素材、画布并列一屏,切模块不换页;顶部常驻项目条(Ep 切换 + 阶段 + 一键建议)承担管理职能。TapNow 的"零层级"+ 完整的项目管理层,一个界面全有。

决策

终版决策 G1–G10

#内容说明
G1项目即工作区:编辑器模块升为项目侧栏(Overview / Episodes / Script / Storyboard / Canvas / Characters / Locations / Files),切模块不换页,0 跳删除 Studio 跳转、Scripts tab、脚本列表三层;1 项目 = 1 创作环境
G2顶部项目条常驻:项目名 · 阶段步进+Advance · 一键建议(集切换在侧栏树,不重复)管理职能(TapNow 缺的层)融进同一界面,跨模块可见
G3项目 → 剧集(episodes 表,已在 project 级)→ 每集自己的 script(script_projects.episode_id 归属,含各自 scenes/shots/renders)。新建剧集自动带空 script;存量 episode_id NULL 的脚本回填默认 Ep 1;一集多 script 时 UI 取最新为主稿零数据迁移——episodes/sort_order/episode_id 全部现成,只是 UI 升级为一等公民
G4侧栏 = 当前集块 + Episodes 管理项:≣ Episodes(一级项)= 管理面(完整列表:集内进度/排序/改名/复制/删除,状态推导);其下只渲染当前集块——集头(边框卡样式)+ 缩进的 Script/Storyboard 子项 = 字面父子层级;集头 ⇄ 点击弹紧凑切换菜单。集数量不影响侧栏高度;切换器全局唯一(顶栏无 Ep chip)。Canvas 顶级;ASSETS 跨集资产层级字面可见 + 可扩展到任意集数;管理面回归一级显眼位
G5Files 吸收 Output:文件夹范式(All/Media/Renders/Docs chips)管文件与生成物展示文件夹只管存与看,不管项目管理
G6Overview 为落地页:Continue(切模块非跳页)+ 建议 + 模块摘要 + 动态Characters/Locations 等资产随 G1 自然成为项目级
G7主页 = A 队列默认(停滞置顶+行内一键)+ C 网格次视图;撤 Internal/External;视图栏 All/Starred/Archived数据源 = 新端点 GET /projects/suggestions
G8双主题一等公民;工作台视觉规范沿用(点式步进/实心 CTA/停滞 token)已上线,不回退
G9UI 英文,中文走 i18n产品规范
G11Canvas ↔ Ep Script = 平行互补 + 引用桥:①Canvas=发散面(项目级草稿纸),Script=收敛面(集级流水线),共享 ASSETS 互不隶属(现状,canvases.project_id + canvas_resource_refs);②近期:画布节点可引用集内 scene/shot 帧拖排审阅(删实体→节点降级快照);③远期:画布 beat/大纲一键"落稿"到某集 Script(AI 辅助,backlog)纸和流水线互不阻塞;誊写(③)与摊看(②)是桥不是绑定
G12集内容 = Script + Storyboard + Renders:Script 打开编辑器(内含 Outline/Beats/Cover 视图,不单列);Renders = 本集产出墙(帧/shot 视频/成片,从本集 shots 推导;与项目级 Files·Renders 同数据、集维度切片)。Publish(发布到平台)为 D2 后预留子项;配音/字幕未建模不画集 = 完整产出链(脚本→分镜→产出→发布)的容器;只画有数据支撑的
G13Characters/Locations = 主库 + 出场:主库(ASSETS)= 项目级聚合视图,实体从各集剧本 cue/场景头自动派生(现状即派生制,零手填零迁移),每条带「出现于 Ep x」徽标;@ 候选升级为项目级(任意集可复用,选中即记出场);集内新写 cue 自动入主库。v2 backlog:实体化真表(设定图/描述),供角色一致性 AI 生成用户模型:总体管理 + 哪集出现 + 集内可建可选,复用零摩擦
G14存储统一到 Supabase Storage(自托管)——用户 2026-07-10 拍板,推翻 ADR #1092(当时"主库不迁对象存储";自托管 Storage 数据仍落 NAS 盘,零云成本,统一运维/备份/权限一套系统)。落地 = 独立 storage-unification epic(不并入本次 UI 重构):①写路径切换——新上传不分大小全走 Storage(TUS 断点续传+Range 流式);②三个功能适配:ffmpeg/转码 POSIX 直读改挂 Storage 卷、sideload O(1) rename 重设计、nginx 302 直出适配;③存量渐进迁移(迁一件改一件 durable URL,旧链服务到迁完)。generated_media object-store flag 即可常开。前端只见 durable URL 零改动,UI 重构零阻塞一套系统;本次 UI 重构零阻塞
G10SOP 阶段保持项目级(v1);集级进度由 Episodes 行内数据表达避免双状态机;若日后需要集级阶段再演进
执行拆分:PR-8 后端(批量 suggestions + 项目自动带 studio 容器)→ PR-9 主页(队列+网格)→ PR-10 项目工作区壳(顶栏+新侧栏+Overview+Episodes 管理面,Files 吸收 Output)→ PR-11 编辑器模块并入(Script/Storyboard/Characters/Locations 挂载到项目侧栏,Ep 切换器上移)→ e2e 双主题。渐进迁移:PR-10 期间旧编辑器路由仍可用,PR-11 完成后下线 Scripts tab 与独立编辑器入口。
