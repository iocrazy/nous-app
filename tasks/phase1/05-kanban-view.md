## 看板逻辑

### 列的来源
- 从当前项目关联的 workflow 获取 nodes
- 按 node_group 分大组，按 sort_order 排列
- 每列标题 = 节点名称，括号内显示该节点的实例数量

### 卡片数据
- 从 GET /projects/{pid}/instances 获取
- 每个实例根据 current_node_ids 放入对应列
- 卡片显示：sequence_id + title + priority + assignee

### 卡片操作
- 点击卡片 → 进入实例详情页
- 卡片右键/更多菜单 → 流转/驳回/跳过/编辑

## Supabase Realtime 订阅

```typescript
// 订阅实例状态变化，实时更新看板
supabase
    .channel('kanban')
    .on('postgres_changes', {
        event: '*',
        schema: 'public',
        table: 'workflow_instances',
        filter: `project_id=eq.${projectId}`
    }, (payload) => {
        // 更新看板数据
        updateKanbanData(payload)
    })
    .on('postgres_changes', {
        event: '*',
        schema: 'public',
        table: 'node_executions',
    }, (payload) => {
        // 更新执行状态
        updateExecutionData(payload)
    })
    .subscribe()
```
